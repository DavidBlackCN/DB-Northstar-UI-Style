界面层级首先是一种阅读顺序

当用户打开一个页面时，他们并不会平均地阅读所有内容。标题、摘要、状态与操作共同组成一条路径。好的界面并不要求注意力，而是让注意力自然地流动。

这也是为什么我们更愿意使用背景、间距与轻边框来划分区域。阴影只留给真正浮在页面之上的元素，例如弹窗或菜单。更多背景资料可以参阅 视觉层级笔记。

“精致”不是增加更多细节，而是让每一个留下来的细节都说得通。
Note品牌色只用于链接、选中状态和关键操作。大面积内容仍然保持中性，让青蓝色成为可靠的方向提示。

一个简单的 Token 起点

先让变量足够容易修改，再从真实页面中观察规律，而不是提前搭建完整系统。

tokens.css
/* quiet surfaces, explicit hierarchy */
:root {
  --surface: #ffffff;
  --surface-soft: #f6f7f7;
  --brand: #5086a1;
  --border: rgb(57 59 64 / 12%);
}

这组变量不是结论，只是共同的实验起点。真正的风格会在 Blog 的阅读节奏、Dashboard 的密度与组件状态之间逐渐显现。
