# Northstar 浏览器验证参考

仅在实现完成前的验收、复杂交互、浮层、响应式或非 DOM 渲染任务中读取。以可观察结果为准，而非“样式已写入”。

## 实施前检查

- 识别现有组件、语义状态、Token、路由状态、Portal、媒体查询、动画、内联样式与 CSS 注入顺序。
- 区分 DOM、Canvas、WebGL、编辑器、终端和图表。优先使用渲染器公开的主题与字体 API。
- 确认动态类、Observer、计时器或全局补丁可重复执行、作用域受限并在卸载或路由切换后清理。

## 验收矩阵

| 维度 | 至少检查 |
| --- | --- |
| 主题 | Light、Dark、默认主题色、最容易出现对比风险的一种替代主题色 |
| 视口 | 桌面与移动；导航、工具栏、分页、表格、弹窗、长文本与横向滚动 |
| 输入 | 指针 hover / press、键盘 focus-visible、触摸目标与无 hover 环境 |
| 组件状态 | default、hover、active、focus-visible、selected、disabled、loading；success、warning、danger、idle、empty、error |
| 浮层 | Tooltip、Popover、Dropdown、Dialog、Drawer、Toast、确认框的背景、文字、边界、箭头、阴影、遮罩、层级与焦点管理 |
| 动态变化 | 主题切换、数据刷新、重新挂载、路由切换、状态恢复与首次使用引导 |

## 观察方法

- 使用截图检查整体构图、重叠、层级、溢出和浮层位置。
- 使用计算样式检查字体家族与字重、颜色、边框宽度、透明度、动画名与持续时间；使用几何尺寸检查固定格式组件是否稳定。
- 对主题和状态执行真实交互后再读取结果，检查旧 transition、filter、opacity 或关键帧没有从错误起点闪烁。
- 确认横向滚动只发生在必要的数据区域，不来自页面壳、侧栏或浮层。
- 对 Canvas / WebGL / 编辑器确认实际绘制结果和主题 API，而非只检查外层 DOM。
- 无法触发或无法验证的状态应在交付中明确列出，不能以静态推断替代浏览器验证。
