# Northstar 示例索引

这些文件是可移植的参考快照。按任务只读取一个最接近的示例，提取 Token、组件状态、页面密度或交互组织方式；不要整体复制、不要将示例中的业务文案或具体结构强加给目标产品。

| 参考文件 | 适用场景 |
| --- | --- |
| [dashboard.html](dashboard.html) | Sidebar、工具栏、KPI、图表、活动流、数据表格与主题选择器。 |
| [blog.html](blog.html) | Blog / Docs 的阅读节奏、文章元数据、代码、Callout、链接与内容布局。 |
| [components.html](components.html) | 按钮、表单、导航、数据展示、浮层、状态矩阵与锚点高亮。 |
| [mobile.html](mobile.html) | 移动端任务应用、底部导航、紧凑主题选择器与触摸布局。 |

示例引用的本地字体路径属于原始项目环境；将其用于其他项目时，根据目标项目实际字体资源与加载方式调整。
