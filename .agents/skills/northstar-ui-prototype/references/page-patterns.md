# Northstar 页面模式参考

仅在确定页面密度、排版宽度或响应式重排时读取。

## Dashboard / 工具型界面

- 保持中等信息密度；用信息分组、网格轨道和稳定尺寸组织 KPI、工具栏、表格和活动流。
- 将 Maple Mono 用于 KPI、ID、版本和技术数值，不让整页变成终端风格。
- 表格与固定格式内容可以局部横向滚动；页面壳、侧栏和浮层不得因内容宽度产生横向溢出。

## Blog / Docs

- 以阅读长度决定内容宽度；正文约 `720px`，层级依赖字号、字重、紧凑字距和 1.5–1.82 行高。
- 正文和长说明保持 Sans；把品牌色限制在链接、Callout、代码和少量元数据。
- 比 Dashboard 留出更多空白，但不使用无意义的大型 Hero 或卡片堆叠。

## Components / Playground

- 同时展示 default、hover、active、disabled、focus-visible、selected 与 loading 的代表状态。
- 使用真实状态属性驱动目录与锚点高亮，例如 `aria-current="location"`；不要把第一个项目硬编码为当前项。
- 展示成功、警告、危险、空和错误状态，确认品牌主题不会吞并其语义色。

## 移动端

- 优先缩减空白、重排信息和按需局部滚动，不缩小触摸目标或隐藏关键操作。
- 保持与桌面相同的语义状态、主题规则和焦点可见性；为固定底栏、弹窗和主题选择器留出安全区域与稳定层级。
